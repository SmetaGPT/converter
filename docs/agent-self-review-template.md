# Agent Self-Review Template

Использовать после нетривиальной задачи.

## Self-review

1. Цель была достигнута полностью, частично или нет?
2. Где процесс был сильным?
3. Где был лишний поиск, лишний ремонт или лишнее расширение scope?
4. Был ли validation достаточно узким и своевременным?
5. Все ли нужные state updates сделаны?
6. Нужен ли новый memory note?
7. Нужен ли новый entry в instruction change log?
8. Что стоит сделать иначе в следующем похожем цикле?
